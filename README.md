# 🎓 Student Management System

A Java-based desktop application with a graphical user interface (GUI) and Oracle 10g database integration.

---

🚀 Features

* ➕ Add Student
* 📋 View Students
* ✏️ Update Student
* ❌ Delete Student
* 💾 Data stored using Oracle Database

---

🛠️ Tech Stack

* Java (Swing)
* Oracle 10g Database
* JDBC (Java Database Connectivity)

⚙️ How to Run

1. Compile:
   javac -cp ".;ojdbc8.jar" studentGUI.java

2. Run:
   java -cp ".;ojdbc8.jar" studentGUI

---

💡 Project Description

This project demonstrates a complete CRUD-based desktop application using Java Swing and Oracle database. It highlights database connectivity using JDBC and real-time data operations through a user-friendly interface.
